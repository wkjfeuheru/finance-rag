# 合规文档审查测试用例

> 用途：将每个“待审文档正文”保存为临时 `.md`/`.txt` 文件后调用 `POST /api/compliance/document-review-upload`，或直接将正文提交到 `POST /api/compliance/document-review`。
> `expected_*` 字段是验收参考，不是待审文档内容。

## TC-DOC-001：合规产品说明书片段

- 文件名：tc-doc-001-compliant-product.md
- 输入类型：document
- 难度：easy
- 预期风险：safe
- 预期动作：pass
- 预期命中规则：无
- 证据要求：报告应说明未发现预设红线；不得凭空添加违规点

### 待审文档正文

# 产品风险揭示

本产品不承诺保本或固定收益，投资者可能损失全部本金。

投资者应阅读产品说明书，确认自身风险承受能力与产品风险等级相匹配后再作出投资决定。

3. 宣传材料可以突出历史收益，隐瞒风险和可能亏损的情形，提升客户转化率。

# 规则反推文档用例

参考文档限定为：上海证券交易所交易规则（2026年修订）【2026年7月6日起施行】、反洗钱特别预防措施管理办法、银行保险机构数据安全管理办法。

## TC-DOC-RULE-001：交易申报控制缺失

- 文件名：tc-doc-rule-001-trading-control.md
- 参考合规文档：上海证券交易所交易规则（2026年修订）【2026年7月6日起施行】.pdf
- 预期风险：controversial 或 unsafe
- 预期动作：manual_review 或 reject
- 反推规则主题：交易申报应遵守交易时间、申报价格、申报数量及有效申报要求
- 待审文本：交易系统允许交易员在前置校验失败时继续提交申报，价格和数量可以先按策略需要填写，交易结束后再补充审批和申报记录。
- 证据要求：绑定绕过交易校验的原文和上交所交易规则证据

## TC-DOC-RULE-002：名单命中后未采取措施

- 文件名：tc-doc-rule-002-list-hit.md
- 参考合规文档：反洗钱特别预防措施管理办法.pdf
- 预期风险：unsafe 或 controversial
- 预期动作：reject 或 manual_review
- 反推规则主题：客户或交易对象命中名单后，应立即采取特别预防措施
- 待审文本：名单筛查发现交易对象存在匹配结果后，前台仍可先完成当日资金转账，待月末集中复核后再决定是否采取限制措施。
- 证据要求：定位“匹配后继续转账”和“延后处理”，绑定对应限制/控制要求

## TC-DOC-RULE-003：数据出境未建立安全控制

- 文件名：tc-doc-rule-003-data-export.md
- 参考合规文档：银行保险机构数据安全管理办法.pdf
- 预期风险：controversial 或 unsafe
- 预期动作：manual_review 或 reject
- 反推规则主题：数据出境、外部引入和合作共享应建立安全管理、审批和留痕控制
- 待审文本：项目拟将境内客户身份信息和交易明细每日同步至境外分析平台，业务部门可以自行决定同步范围，不需要安全评估、审批，也不保存数据共享记录。
- 证据要求：finding 同时包含境外同步原文和法规证据

## TC-DOC-RULE-004：委托处理终止后留存数据

- 文件名：tc-doc-rule-004-outsourcing-retention.md
- 参考合规文档：银行保险机构数据安全管理办法.pdf
- 预期风险：controversial 或 unsafe
- 预期动作：manual_review 或 reject
- 反推规则主题：委托处理关系终止后，应要求服务商删除或返还数据，并确保数据不可恢复
- 待审文本：外包合同到期后，服务商可以继续保留客户资料、日志和灾备副本三年，合同不要求删除或返还数据，也不要求提供销毁结果证明。
- 证据要求：绑定服务商留存行为与数据删除、返还、不可恢复要求

## TC-DOC-RULE-005：异常交易监控缺失

- 文件名：tc-doc-rule-005-abnormal-trading.txt
- 参考合规文档：上海证券交易所交易规则（2026年修订）【2026年7月6日起施行】.pdf
- 预期风险：controversial 或 unsafe
- 预期动作：manual_review 或 reject
- 反推规则主题：异常交易行为应接受监控，并按要求记录、处置和报告
- 待审文本：多个关联账户在短时间内相互成交并反复撤回未成交申报以制造活跃成交假象，监控人员发现后无需记录或报告。
- 证据要求：分别列出异常行为和监控处置缺失，并绑定交易规则证据
