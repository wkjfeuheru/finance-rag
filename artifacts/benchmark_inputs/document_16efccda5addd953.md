# 可转债投资操作指南

## 1. 可转债基本概念

可转债（Convertible Bond），全称"可转换公司债券"，是上市公司依法发行、在一定期限内可以按照约定条件转换为公司股票的债券。它兼具**债券的保底属性**和**股票的上涨弹性**，被称为"进可攻、退可守"的投资品种。

可转债的核心要素包括：
- **面值**：每张可转债面值100元，这是价格的"锚"，也是赎回保底的基础。无论可转债市价如何波动，到期时如未转股可按面值加利息被公司赎回。
- **票面利率**：可转债的票面利率较低，通常年化0.2%-3.0%，远低于同期限普通信用债（后者通常在3%-6%）。这是因为可转债的"转股期权"具有额外价值，投资者愿意接受较低的利率。
- **转股价**：投资者将可转债转换为公司股票时的定价。例如转股价为10元/股时，每张可转债（面值100元）可转换为10股（100÷10）。转股价在可转债发行时确定，后续可能因分红、配股、下修等事件调整。
- **转股价值**：转股价值 = (100 / 转股价) × 当前正股价格。这个数值反映将可转债立即转换为股票后的市场价值。例如：转股价10元，正股价12元，转股价值 = (100/10)×12 = 120元。
- **转股溢价率**：溢价率 = (可转债市价 / 转股价值) - 1。这是最重要的估值指标之一。溢价率越低（甚至为负），可转债的"股性"越强，跟随正股波动的关联度越高；溢价率越高，"债性"越强，更多受债券属性支撑。
- **到期赎回价**：可转债到期时，发行公司赎回未转股可转债的价格，通常为面值加上最后一期利息（一般103-110元之间）。历史上大多数可转债都是以"转股"方式结束存续，而非被到期赎回。

### 1.1 可转债与普通信用债的区别
可转债与传统信用债有几个关键区别：第一，可转债票面利率远低于同期限普通债，投资者的主要收益来源是转股增值而非利息收入；第二，可转债可以转换为股票，具有上涨弹性，而普通债收益上限为到期本息；第三，可转债上市交易活跃度通常高于普通债，流动性更好；第四，可转债的交易规则不同，支持T+0回转交易，且无涨跌幅限制。

### 1.2 中国可转债市场概况
中国可转债市场自2017年信用申购改革后进入高速发展阶段，从2017年初的不足20只存量可转债增长至2025年超过500只。市场规模从不足1,000亿元增长到超过1万亿元。主要的发行行业包括银行、券商、电力、化工、电子、医药等。

## 2. 可转债的申购（打新债）

### 2.1 申购条件
自2022年6月18日起，可转债申购新规正式实施，提高了准入门槛：
1. 投资者需拥有证券账户（沪深A股账户均可），且账户开通满2年以上。
2. 申请权限开通前20个交易日，证券账户及资金账户内的日均资产不低于**10万元**（不含通过融资融券融入的资金和证券）。
3. 参与证券交易经验满24个月（以首次交易日期起算）。
4. 已签署《向不特定对象发行的可转换公司债券投资风险揭示书》。

### 2.2 申购流程
1. 登录券商APP，在"新股/新债申购"菜单中查看当日可申购的可转债列表。
2. 选择目标可转债，点击"顶格申购"（通常为100万张，即1,000手，金额100万元）。注意：顶格申购不代表会中这么多，而是为了最大化中签概率。
3. 提交申购申请当日为T日，T日申购无需预存任何资金。
4. T+1日公布中签率。热门可转债的中签率通常只有0.001%-0.05%。
5. T+2日公布中签结果，投资者可在交易软件中查询是否中签。中签者需在T+2日16:00前确保账户有足额资金（通常中1签为10张共1,000元）。
6. 如余额不足，视为放弃缴款。同一天中签多只可转债且余额不足的，按申购提交时间先后顺序扣款。
7. 缴款成功后等待可转债上市，一般申购后15-25个交易日挂牌上市交易。

### 2.3 申购策略与注意事项
- **坚持申购**：可转债申购被老股民戏称为"捡钱"，因为上市首日平均收益率通常为正。统计显示2020-2025年间，超过85%的可转债上市首日价格高于发行价100元。
- 在股市大幅下跌期间，可转债上市首日破发（跌破100元）的风险增加。建议申购前关注：正股基本面是否健康、转股溢价率是否合理（申购时转股价值低于80元需谨慎）。
- 中签后如遇市场大跌导致上市可能破发，可选择弃购（不缴款），但连续12个月内累计3次弃购将被列入"打新黑名单"，6个月内无法参与任何新股新债申购。
- 上市首日卖出是最常用的策略——俗称"打新一枪"。若对正股中长期走势有信心，也可持有至目标价位（如120元或130元强赎触发价附近）再卖出。

## 3. 可转债的交易规则

### 3.1 基本交易规则
| 项目 | 上海市场 | 深圳市场 |
|------|----------|----------|
| 交易代码 | 11开头（如113xxx） | 12开头（如123xxx） |
| 交易方式 | T+0（当日买入当日可卖出） | T+0 |
| 最小交易单位 | 10张（1手，面值1,000元） | 10张 |
| 最小报价单位 | 0.01元 | 0.001元 |
| 交易佣金 | 约0.02%（双向收取） | 约0.02%（双向收取） |
| 印花税 | 免收 | 免收 |
| 涨跌幅限制 | 无（但有临停机制） | 无（但有临停机制） |

### 3.2 盘中临时停牌机制
- 盘中成交价较前收盘价**首次上涨或下跌达到20%**时：盘中临时停牌30分钟。
- 盘中成交价较前收盘价**首次上涨或下跌达到30%**时：盘中临时停牌至14:57（即尾盘三分钟）。
- 临时停牌时间跨越14:57的，于当日14:57自动复牌进入收盘集合竞价。
- 停牌期间投资者可以继续提交买卖申报（挂单），也可以撤销申报。
- 停牌期间交易所不接受撤单后再重新申报的操作。

### 3.3 集合竞价规则
- **上市首日**：开盘集合竞价的有效申报价格范围为发行价的70%至130%（即70-130元区间）。深市可转债上市首日不设开盘集合竞价，直接进入连续竞价。
- **非上市首日**：开盘集合竞价的有效申报价格范围为前收盘价的90%至110%（即±10%范围内）。

### 3.4 可转债与正股的联动交易
可转债的价格与正股价格高度相关。当正股涨停而无法买入时，部分投资者会转向买入对应的可转债来间接获取上涨收益。但因为转债当日无涨跌幅限制，其价格可能在正股涨停后继续大幅上涨（甚至当天涨50%以上），风险也随之放大。

## 4. 可转债的转股操作

### 4.1 转股条件与时间
- 可转债上市**满6个月**后进入转股期，此后方可申请转股。
- 转股申报时间为每个交易日的9:30-11:30和13:00-15:00。
- 转股数量 = 可转债面值总额（张数 × 100元）÷ 转股价。计算出现零股（不足1股）的部分，由发行公司在转股日后的5个交易日内以现金兑付。
- 转股申报**一经提交不可撤销**，请仔细核对转股张数。

### 4.2 转股操作流程
1. 登录券商APP，找到"可转债转股"功能菜单（通常在"更多交易"→"债券业务"或搜索"转股"）。
2. 选择需要转股的可转债代码。
3. 输入转股数量（按张数，最低10张起转，也就是1手）。
4. 确认提交转股申请。请注意：转股申请提交后立即生效，不可撤销。
5. 转股后获得的股票（正股）于**T+1日**到账，到账后方可卖出。
6. 转股过程中不收取任何费用。

### 4.3 转股套利（负溢价套利）详解
当可转债出现**负溢价**（转债市价 < 转股价值，即转股溢价率为负值）时，理论上存在跨品种套利机会。操作步骤如下：
1. 在二级市场以低于转股价值的价格买入可转债。
2. 立即申请转股。
3. T+1日收到正股后在二级市场卖出。
4. 理论获利 = 转股价值 - 转债买入成本 - 交易费用 - 冲击成本。

但实际操作中需注意以下风险：首先，T+1日正股价格可能下跌，吞噬甚至超过套利空间，这就是隔夜风险；其次，大量投资者同时进行转股套利可能导致T+1日正股集中抛售，压低卖出价格；再次，负溢价通常只在正股流动性极好且可转债流动性较差的场景下出现，这本身意味着正股可能存在下跌预期。建议仅在转股溢价率低于-1.5%且正股基本面良好的情况下谨慎尝试。

## 5. 可转债的四大核心条款

### 5.1 赎回条款（强赎条款）
这是投资者**最需要警惕**的条款。条件通常为：在转股期内，如果公司股票在任意连续30个交易日中，至少有15个交易日的收盘价不低于当期转股价的130%（含130%），公司即有权按照约定的赎回价格（一般为面值加当期应计利息，合计约101-103元）赎回全部尚未转股的可转债。

对投资者的实操影响：触发强赎条件后，公司一般会在1-3个交易日内发布"提前赎回公告"。公告中会明确赎回登记日（即最后可操作日）。投资者在赎回登记日前必须做出选择：**卖出可转债**（市价通常在130元以上，远高于赎回价约101元）或**申请转股**。如果既不卖出也不转股，可转债将被公司按约101元强制赎回，大幅亏损。每年都有少数投资者因疏忽错过操作时间而蒙受损失，这是可转债投资中最大的人为操作风险。

### 5.2 回售条款（投资者保护条款）
这是保护投资者的条款。条件通常为：在可转债存续期的最后两个计息年度内，如果公司股票在任何连续30个交易日的收盘价低于当期转股价的70%，投资者有权将其持有的全部或部分可转债，按照约定的回售价格（一般为面值加当期应计利息，合计约103元）回售给发行公司。

回售条款的实际意义在于：当股价持续大幅下跌、正股表现不佳导致可转债市价低于103元时，回售权为投资者提供了"保底止损"机制。如果可转债市价在100元左右，投资者可以选择持有等待回售触发，获得约3%的保底收益。但需要注意的是：公司在回售条件即将触发前，通常会采取行动（如下修转股价）来避免实际被回售，因为被回售意味着公司需要拿出大量现金。

### 5.3 转股价下修条款
当公司股票价格持续低迷时，为了提升可转债的投资吸引力并避免可能触发的回售，公司可以通过一定的程序**下调转股价**。条件通常为：当公司股票在任意连续20个或30个交易日中，有至少10个或15个交易日的收盘价低于当期转股价的一定比例（通常为80%或85%）时，公司董事会有权提出转股价下修方案，提交股东大会审议。方案需经出席股东大会的股东所持表决权的三分之二以上通过方可实施，且持有可转债的股东需回避表决。

转股价下修对投资者的影响：假设转股价从10元下修至8元，那么每张可转债（面值100元）可转换的股数从10股增加到12.5股（100÷8），转股价值从120元升至150元（假设正股价仍为12元），可转债市价通常随之大幅上涨。因此，"博弈下修"是可转债投资中重要的盈利模式之一。

### 5.4 回售与下修的博弈逻辑
当回售条件即将被触发时，公司面临两个选择：**接受回售**（需要拿出大量现金偿还投资者）或**下修转股价**（提升转股价值，推动可转债价格上涨至回售价以上，投资者就不想回售了）。绝大多数上市公司倾向于后者——因为下修转股价虽然会稀释原股东权益，但不需要公司拿出真金白银。投资者可以利用这一博弈逻辑，在回售条件接近触发时布局那些有较强下修意愿的可转债。

## 6. 可转债的定价与估值

### 6.1 可转债的理论价值拆解
可转债的理论价格 = 纯债价值 + 转股期权价值 - 信用风险溢价 - 提前赎回折价。其中：
- 纯债价值：将可转债视为纯债券，按照市场同期限利率折现未来现金流（利息+到期赎回价）得到的现值。如果可转债市价接近或低于纯债价值，说明下跌空间有限，具有"债底保护"。
- 转股期权价值：可转债内含的欧式/美式看涨期权，其价值取决于正股价格、转股价、剩余期限、正股波动率、无风险利率等。剩余期限越长、正股波动率越大，期权价值越高。
- 信用风险溢价：发行公司的信用状况越好（如大型银行、央企），溢价越低；中小民企的溢价更高。

### 6.2 关键估值指标速查表
| 指标 | 计算公式 | 投资参考 |
|------|----------|----------|
| 转股溢价率 | (转债价 / 转股价值) - 1 | <10%→偏股性；10%-30%→平衡型；>30%→偏债性 |
| 纯债溢价率 | (转债价 / 纯债价值) - 1 | 越低越安全，负值→有债底保护 |
| 到期收益率(YTM) | 求解内部收益率 | >0→持有到期不亏本；<0→需靠转股才能盈利 |
| Delta | 转债价变动 / 正股价变动 | 接近1→股性强；接近0→债性强 |
| 剩余年限 | 到期日 - 当前日 | 越长→时间价值越大，期权越值钱 |

## 7. 可转债的投资策略体系

### 7.1 打新策略（最基础）
坚持申购每一只可转债，中签上市后择机卖出。这是最简单的可转债策略，适合所有有证券账户且满足准入条件的投资者。上市首日或上市后短期内卖出，属于"套利"性质的操作，不承担长期价格波动风险。但这个策略的前提是"能中签"，随着参与人数增多，中签率越来越低，策略容量有限。

### 7.2 双低策略（最经典）
"双低"即可转债的**价格低** + **转股溢价率低**。筛选标准通常为：价格低于115-120元且转股溢价率低于20%-25%。操作方法是：每月或每季度按双低指标对所有可转债排名，选取排名靠前的20-30只构建等权组合，下一轮根据最新排名进行调仓（卖出排名下滑的、买入排名上升的）。双低策略的盈利逻辑是：价格低提供下跌保护，溢价率低保证正股上涨时转债能跟上。历史回测数据显示，双低策略年化收益率在8%-15%之间，波动率远低于正股。

### 7.3 偏债型防守策略
在可转债价格处于面值附近（100-110元）、到期收益率大于零时买入持有。这是一种"先求不败、再求胜"的防守反击策略。持有期间赚取少量利息收益（虽然可转债票面利率低），同时等待两个"催化剂"：一是正股行情转好，可转债跟随上涨；二是下修条款触发，转股价值突然提升。这个策略适合在熊市底部区域或市场前景不明朗时使用，防守效果突出，但进攻性较弱。

### 7.4 正股替代策略
当某只可转债的转股溢价率极低（甚至为负值）且投资者中长期看好该股票时，可以考虑用持有可转债来替代直接持有正股。这样做的好处是：保留了正股上涨的绝大部分收益（溢价率为负时甚至可获得更多），同时如果正股大幅下跌，可转债有债券的"底"保护（100元面值附近），跌幅会明显小于正股。举个例子：一只股票价格10元，对应可转债价格105元、溢价率为5%。如果股价涨到15元（涨50%），转债可能从105元涨到约150元（涨43%），仅略低于正股涨幅；如果股价跌到6元（跌40%），转债可能跌到约97元（跌7.6%），因为有债券价值托底，跌幅远小于正股。

## 8. 风险提示总结

1. **强制赎回风险（最严重）**：触发强赎后如未及时操作，按约101元被赎回而市价在130元以上，瞬间亏损超过22%。这是可转债投资中**唯一可能归因于投资者自身疏忽**的重大风险。解决方案：关注持仓可转债的强赎公告，设好日历提醒。
2. **信用违约风险**：虽然中国可转债历史上尚未有实质违约案例，但理论上存在发行公司破产、无法兑付本息的风险。投资者需关注公司的信用评级和财务状况。
3. **流动性枯竭风险**：部分小市值公司发行的可转债日均成交额可能只有几十万元，大额资金进出困难，冲击成本高。
4. **系统性下跌风险**：在股市大幅下跌期间（如2022年、2024年部分时段），可转债也会跟随下跌，尤其是高溢价率品种抗跌性较弱。
5. **条款理解和操作风险**：投资者如不充分理解强赎、回售、下修等条款，可能在关键时间节点做出错误判断。建议每次投资前仔细阅读可转债募集说明书全文。
6. **价格操纵风险**：体量较小的可转债存在被少数资金操纵的可能，价格短期内可能出现异常波动，追高买入有被"闷杀"的风险。
