# 股票投资入门指南

## 1. 什么是股票

股票是股份有限公司发行的一种所有权凭证，代表持有者对公司的部分所有权。购买股票即成为公司的股东，享有公司盈利分红、重大决策投票等权利。股票可在二级市场（证券交易所）进行买卖交易，其价格受公司业绩、行业前景宏观经济等多重因素影响而产生波动。

股票投资的核心逻辑是低买高卖——以较低价格买入潜力股票，以更高价格卖出获利。不同于银行存款的固定收益，股票投资具有高收益高风险的特征，投资者可能获得丰厚回报，也可能面临本金损失。

## 2. 开户条件与交易渠道

### 2.1 开户资格条件
- 年满18周岁，具有完全民事行为能力。
- 持有中华人民共和国居民身份证。
- 需先开立证券账户和资金账户。
- 需完成风险承受能力评估。

### 2.2 账户类型
1. **证券账户**：用于买卖股票，记录持有的股票数量。在中国证券登记结算有限责任公司开立。
2. **资金账户**：用于存取买卖股票的资金，在券商开立。
3. **股东账户**：分为上海股东账户和深圳股东账户，分别对应沪深交易所。

### 2.3 开户渠道
1. **线下营业部**：持身份证前往券商营业部现场办理，工作时间均可办理。
2. **线上开户**：通过券商官方APP或官网在线开户，需完成视频认证、风险测评等步骤，整个流程约15-20分钟。
3. **第三方平台**：如同花顺、东方财富等开户，实质也是通过券商开户。

### 2.4 主流券商选择
选择券商需关注以下因素：佣金费率、交易软件稳定性、线下网点覆盖、客户服务质量等。大型券商如中信证券、华泰证券、国泰君安等综合实力较强，佣金费率也较为透明。

## 3. 股票交易规则

### 3.1 交易时间
| 时间段 | 具体时间 | 说明 |
|--------|----------|------|
| 集合竞价 | 9:15-9:25 | 可申报也可撤单 |
| 连续竞价 | 9:30-11:30 | 上午正常交易时段 |
| 午间休市 | 11:30-13:00 | 不交易 |
| 连续竞价 | 13:00-14:57 | 下午正常交易时段 |
| 集合竞价 | 14:57-15:00 | 可申报不可撤单 |

### 3.2 交易单位
- 股票最小交易单位为**100股**（1手）。
- 买入数量必须是100股的整数倍。
- 卖出时若持有不足100股，可一次性全部卖出。

### 3.3 涨跌幅限制
- 普通股票：涨跌幅限制为**10%**。
- ST股票：涨跌幅限制为**5%**。
- 科创板、创业板：涨跌幅限制为**20%**。
- 新股上市首日：无涨跌幅限制，但有盘中临时停牌机制。

### 3.4 交易费用
| 费用类型 | 收费标准 |
|----------|----------|
| 佣金 | 最低5元，最高不超过成交金额的千分之三 |
| 印花税 | 卖出时收取成交金额的千分之一 |
| 过户费 | 买卖成交金额的十万分之二（沪市） |
| 规费 | 约万分之0.687 |

## 4. 股票基本面分析

### 4.1 财务指标
- **市盈率（PE）**：股票价格与每股收益的比率，越低说明估值越便宜。
- **市净率（PB）**：股票价格与每股净资产的比率，适用于金融类公司。
- **净利润增长率**：反映公司盈利增长速度，越高说明成长性越好。
- **资产负债率**：反映公司债务水平，一般不超过60%较为稳健。

### 4.2 重要财务报告
- **年报**：每年3-4月发布，反映上一年度完整经营情况。
- **中报**：每年7-8月发布，反映上半年经营情况。
- **季报**：每个季度结束后一个月内发布。

### 4.3 行业分析
- 关注行业发展周期（初创期、成长期、成熟期、衰退期）。
- 政策支持力度对行业发展影响重大。
- 行业竞争格局决定公司盈利空间。

## 5. 股票技术分析基础

### 5.1 常见技术指标
- **均线（MA）**：5日、10日、20日、60日均线反映不同周期价格走势。
- **MACD**：判断趋势方向和买卖信号的金叉死叉。
- **KDJ**：超买超卖指标，用于判断短期波动。
- **成交量**：反映市场活跃度和资金流向。

### 5.2 K线基础
- **阳线**：收盘价高于开盘价，表示上涨。
- **阴线**：收盘价低于开盘价，表示下跌。
- **上影线**：最高价与实体上端的差距。
- **下影线**：最低价与实体下端的差距。

### 5.3 趋势线
- **上升趋势线**：连接逐步升高的低点，形成支撑线。
- **下降趋势线**：连接逐步降低的高点，形成压力线。
- 有效突破趋势线往往意味着趋势反转。

## 6. 股票筛选方法

### 6.1 价值投资筛选法
1. 选择行业龙头或细分领域冠军。
2. 市盈率低于行业平均水平。
3. 净利润连续3年以上稳定增长。
4. 资产负债率适中，现金流充裕。

### 6.2 趋势投资筛选法
1. 股价站上20日均线且均线向上发散。
2. 成交量持续放大，资金明显流入。
3. MACD金叉且位于零轴上方。
4. 板块出现集体启动信号。

### 6.3 简单筛选指标组合
| 指标 | 筛选标准 |
|------|----------|
| PE | 0-30倍 |
| PB | 0-3倍 |
| ROE | 大于15% |
| 净利润增速 | 大于10% |
| 股息率 | 大于2% |

## 7. 仓位管理策略

### 7.1 仓位控制原则
- 建仓初期仓位不超过30%。
- 单只股票仓位不超过总资金的20%。
- 行业集中度不超过40%。
- 始终保留10%-20%现金应对突发情况。

### 7.2 分批建仓法
- 第一次买入：计划仓位的30%。
- 下跌10%后买入：计划仓位的30%。
- 再下跌10%后买入：计划仓位的40%。

### 7.3 金字塔加仓法
- 价格上涨时递减加仓，越涨买得越少。
- 价格下跌时递增加仓，越跌买得越多。
- 适合震荡行情。

## 8. 止损止盈策略

### 8.1 止损原则
- 固定止损：亏损达到7%-10%时无条件止损。
- 移动止损：盈利后止损点上移至成本价。
- 逻辑止损：公司基本面恶化时立即止损。

### 8.2 止盈策略
- 目标止盈：达到预设收益率（如20%）后分批卖出。
- 估值止盈：市盈率超过合理区间30%时开始减仓。
- 技术止盈：跌破重要均线或趋势线时退出。

### 8.3 心态管理
- 避免频繁交易，减少手续费损耗。
- 不要把鸡蛋放在一个篮子里。
- 设定合理的收益预期，年化15%-20%已是优秀水平。

## 9. 常见误区与风险提示

### 9.1 新手常见误区
- 盲目追涨杀跌，听信小道消息。
- 过度集中持仓，单只股票占比过高。
- 频繁短线交易，试图抓住每一个波动。
- 没有止损纪律，亏损后死扛。

### 9.2 投资风险
- **市场风险**：整体下跌导致股票贬值。
- **流动性风险**：股票停牌或跌停时无法卖出。
- **公司风险**：公司经营不善导致退市。
- **政策风险**：监管政策变化影响股价。

### 9.3 风险控制建议
- 用闲钱投资，不影响生活需求。
- 分散投资，不要单吊一只股票。
- 持续学习，提高投资认知。
- 保持理性，避免情绪化决策。
